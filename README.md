## 退款：三天和 10GB 是两个硬门槛

按 WePC 的退款规则，购买后三天以内且流量使用不超过 10GB，可以全额退到账户余额，或者每笔扣 10 元手续费后原路退回。超过三天，或者用量超过 10GB，就不能原路退了，只能按比例扣除已使用部分后退到余额，而余额不可提现。

这条规则对买来试线路的读者很关键：三天时间够你测一次延迟和丢包，10GB 流量够跑几轮测速加短时推流。测完不合适就退，损失可控。反过来，如果你打算“先买一个月用着看，不行再说”，超过三天就只能拿回余额，等于钱留在了账户里。

部分标注不支持退款的产品不在这个范围内，下单页会单独注明，付钱之前扫一眼。

**二、机房到底在哪。** 前面提到的“纽约 Cogent 家宽”挂在洛杉矶产品组下，这类命名错位在下单前用订单页或工单核实一次，比事后迁移省事。

**三、库存状态。** 第三方汇总里出现过部分 9929 机型缺货的记录，说明这个系列不是随时有货。看中某一款尽早下单，别等到活动最后一天。

## 常见问题

**黑五期间 WEPC 会单独打折吗？**

官网产品页当前展示的是常规标价，没有黑五专属折扣页。能用的减价手段是优惠码，而第三方整理的优惠码说明里把美国家宽系列排除在外。

**流量用超了会停机吗？**

不会。美国机型超量后限速 3Mbps，香港机型限速 5Mbps，服务继续可用，但直播推流会受影响。

**优惠码怎么用？**

在结账页的 Promotion 输入框填写，点 Validate Code 验证，生效会显示折扣金额。不生效就是该套餐不适用。

**三天内一定能全额退款吗？**

要同时满足两个条件：购买不超过三天，且流量使用不超过 10GB。全额退可以选择退到余额，或者每笔扣 10 元手续费原路退回。

**香港机房国内访问快吗？**

页面自己写的是“三网绕路”。联通用户体验较好，电信和移动不要期待低延迟，追求回国速度请看美国 9929 那两款。

**这几款能拿来建站吗？**

技术上能，但 0.5GB 内存跑不动宝塔加数据库这类组合。真要做站，同价位有更合适的机房 VPS。
